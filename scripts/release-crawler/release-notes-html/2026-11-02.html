containerd/nerdctl

Release notes for v2.4.2

2026-10-30

Changes

  • nerdctl container:
    • Add --device-cgroup-rule to nerdctl run and nerdctl create (#5258, thanks to @takumi12311123)
    • Add --timeout to nerdctl commit for configuring the lease timeout, which was hard-coded to 1h (#5253, thanks to @Luckydog691)
    • Fix --volumes-from to inherit only user mounts, so that the target container’s own /dev/shm configuration is not replaced (#5250, thanks to @git-jxj)
    • Exit with status 1 when detaching from nerdctl attach, as Docker does (#5281, thanks to @cvas22)
  • Healthcheck:
    • Support --health-start-interval for nerdctl run and nerdctl create, healthcheck.start_interval in Compose, and HEALTHCHECK --start-interval in images (#5229, thanks to @akashchamp)
  • nerdctl image:
    • Fix nerdctl image prune --filter until= (empty value) dropping the filter and removing every unused image (#5304, thanks to @ogulcanaydogan)
    • Fix nerdctl rmi -f failing with image ":": already exists when force-removing more than one image used by running containers (#5191, thanks to @ogulcanaydogan)
    • Enable the image verifier of stargz-snapshotter v0.19, so that images with faked DiffIDs are detected (#5264, thanks to @ktock)
  • nerdctl network:
    • Reject invalid nerdctl network ls filters (#5226, thanks to @immanuwell)
  • nerdctl volume:
    • Reject invalid nerdctl volume ls filters (#5252, thanks to @immanuwell)
  • nerdctl compose:
    • Support device_cgroup_rules (#5258, thanks to @takumi12311123)
    • Fix nerdctl compose images to report the pinned image after retagging (#5251, thanks to @git-jxj)
    • Fix nerdctl compose up on Windows by not defaulting --hostname to the service name (#5267, thanks to @0x000NULL)
  • nerdctl logs:
    • Fix log rotation failing on Windows while nerdctl logs -f is running (#5266, thanks to @0x000NULL)
  • go.mod:
    • Update containerd library to v2.4.2 (#5278)
  • nerdctl-full:
    • Update containerd (2.4.2), BuildKit (0.34.1), RootlessKit (3.3.0), stargz-snapshotter (0.19.1) (#5298, #5264, thanks to @ktock)
      • containerd v2.4.2 fixes CVE-2026-95839, GHSA-8647-2jxj-p2rc, GHSA-hc94-p972-ch66

Compatible containerd versions

This release of nerdctl is expected to be used with containerd v1.7 or later. Some features may not work with other releases of containerd.

About the binaries

  • Minimal (nerdctl-2.4.2-linux-amd64.tar.gz): nerdctl only
  • Full (nerdctl-full-2.4.2-linux-amd64.tar.gz): Includes dependencies such as containerd, runc, and CNI

Quick start

Rootful

$ sudo systemctl enable --now containerd
$ sudo nerdctl run -d --name nginx -p 80:80 nginx:alpine

Rootless

$ containerd-rootless-setuptool.sh install
$ nerdctl run -d --name nginx -p 8080:80 nginx:alpine

Enabling cgroup v2 is highly recommended for rootless mode, see https://rootlesscontaine.rs/getting-started/common/cgroup2/ .

  • [CHANGE] API: The experimental search endpoints now clamp batch_size to 1000. (#19731, @roidelapluie)

  • [CHANGE] PromQL: Subquery samples are now included in the query TotalSamples and TotalSamplesPerStep statistics, and SamplesRead now counts reads from subqueries with an @ modifier in range queries. (#19165, @DanCech)
  • [CHANGE] Remote write: Stop exposing the deprecated prometheus_remote_storage_metadata_total, prometheus_remote_storage_metadata_failed_total, prometheus_remote_storage_metadata_retried_total, and prometheus_remote_storage_metadata_bytes_total metrics for Remote Write 2.0 queues.   • [CHANGE] TSDB: Reject exemplars whose label names are not unique, instead of storing them and serving a duplicate JSON key from /api/v1/query_exemplars. (#19896, @Ramya-9353)
  • [FEATURE] API: Allow overriding PromQL Start Timestamp processing on a per-query basis using the X-Prometheus-Use-Start-Timestamps HTTP header. (#19066, @69iqqq)
  • [FEATURE] Agent: Support metadata-wal-records in Prometheus Agent mode. (#19684, @bwplotka)
