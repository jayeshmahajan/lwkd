coredns/coredns

Release notes for v1.15.0

2026-10-21

This release improves DNS caching, forwarding, and transport reliability, with fixes for stale-cache handling, upstream connections, crashes/race fixes, as well as enhancemence from quite a few plugins.

Forwarding now supports DNS-over-QUIC upstreams. Additional new features include optional JSON query logging, authenticated RFC 2136 dynamic DNS updates, SIIT support, expr-lang templates, and PROXY protocol v2 metadata.

The release is built with Go 1.27.3, covering CVE-2026-56865, CVE-2026-56864, CVE-2026-33818, CVE-2026-97032, CVE-2026-78659, CVE-2026-97031, and CVE-2026-111943, along with other security fixes.
